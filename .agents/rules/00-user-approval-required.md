# User Approval Required for Code Changes

## Rule
1. **Mandatory Approval Before Coding**:
   - The agent MUST NOT write, edit, delete, commit, or push any code without explicit approval from the user.
2. **Planning First**:
   - For any feature, bug fix, or refactor, first present a clear plan, specification, or design options.
   - Stop and wait for the user to review and explicitly approve before making any modifications to the codebase.
